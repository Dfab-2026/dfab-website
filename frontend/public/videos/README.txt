DFAB Projects scroll-video slot

The included `products-scroll.mp4` is a lightweight SAMPLE VIDEO so the Projects
page scroll-scrub effect can be tested immediately.

To use the final DFAB video later:
1. Keep this folder: frontend/public/videos/
2. Replace `products-scroll.mp4` with your final MP4.
3. Keep the filename exactly: products-scroll.mp4
4. Recommended: MP4/H.264, yuv420p, 16:9, 1080p, web optimized / fast-start.
5. Restart the frontend after replacing the file while testing locally.

No code change is required when the filename stays the same.
